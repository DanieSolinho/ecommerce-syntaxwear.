# SyntaxWear - Tênis e Sneakers Online

## Descrição do Projeto
Compre os melhores tênis e sneakers online na SyntaxWear. Encontre os modelos mais estilosos e confortáveis para todas as ocasiões. Frete grátis e entrega rápida!

Este projeto é um protótipo de uma loja online de tênis e sneakers, desenvolvido utilizando apenas HTML5 e CSS3, com foco em um design responsivo e moderno.

## Funcionalidades
*   Design responsivo, adaptável a diferentes tamanhos de tela (desktop, tablet, mobile).
*   Seções para categorias de produtos (Casual, Esporte, Moderno, Futurista).
*   Grid de produtos em destaque.
*   Navegação intuitiva com menu principal e secundário.
*   Formulário de inscrição para newsletter no rodapé.
*   Links para redes sociais.

## Tecnologias Utilizadas
*   **HTML5:** Para a estruturação do conteúdo da página.
*   **CSS3:** Para estilização, layout e responsividade do site.

## Estrutura de Pastas
```
.
├───css/
│   ├───base.css
│   ├───reset.css
│   ├───variables.css
│   └───components/
│       ├───footer.css
│       ├───header.css
│       ├───hero.css
│       ├───product-category.css
│       └───product.grid.css
├───images/
│   ├───banners/
│   ├───favicons/
│   ├───icons/
│   └───logo/
│   └───produtos/
├───index.html
└───README.md
```

*   `index.html`: O arquivo principal HTML que contém a estrutura do site.
*   `css/`: Contém todos os arquivos de estilo CSS, organizados em arquivos base e componentes específicos.
    *   `reset.css`: Remove estilos padrão do navegador.
    *   `variables.css`: Define variáveis CSS para cores, fontes, etc.
    *   `base.css`: Estilos gerais e tipografia.
    *   `layout.css`: Estilos para o layout geral da página.
    *   `components/`: Contém estilos específicos para cada componente da UI (cabeçalho, hero, categorias de produto, grid de produtos, rodapé).
*   `images/`: Contém todas as imagens utilizadas no projeto, categorizadas por tipo (banners, ícones, logo, produtos).
*   `js/`: Vazio, indicando que este projeto não utiliza JavaScript no lado do cliente.

## Como Visualizar o Projeto
Para visualizar o projeto, siga os passos abaixo:

1.  **Clone o repositório** (se aplicável, assumindo que este é um projeto local, você já o tem).
2.  **Abra o arquivo `index.html`** em seu navegador web preferido (Chrome, Firefox, Edge, Safari, etc.).

Não é necessário nenhum servidor web ou ferramenta de compilação, pois o projeto é puramente estático.
